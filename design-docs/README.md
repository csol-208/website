# Design Documents

This folder contains planning and concept documents used during the initial design and development of the course website. These files are **not part of the live website** and are kept for reference only.

## Contents

- **idea.md** - Original course concept and syllabus design with AI-augmented learning philosophy
- **Course-Syllabus.md** - Early syllabus draft and structure
- **logistics.md** - Planning notes for course logistics
- **readings-ideas.md** - Reading material ideas and resources

## Note

For the **actual live website content**, see the `src/` directory:
- Homepage: `src/index.html`
- Syllabus: `src/syllabus.html`
- Policies: `src/policies.html`
- Tech Setup: `src/setup.html`
