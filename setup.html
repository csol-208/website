Technical Setup Guide

Required tools and accounts for the course

Before the first class: Please complete all steps below to ensure you're ready for hands-on work from day one.

computer Hardware Requirements

  • Laptop or tablet with keyboard: Must have a modern web browser (Chrome, Firefox, Safari, or Edge)
  • Battery or power cable: Ensure your device can last for 2-hour sessions
  • Internet connection: Reliable access for cloud-based development tools

code 1. GitHub Account & Student Developer Pack

GitHub will be our primary platform for coursework and collaboration.

Step 1: Create a GitHub Account

If you don't already have one, create a free account at github.com/signup

Step 2: Apply for GitHub Student Developer Pack

The Student Developer Pack gives you free access to:

  • GitHub Copilot: AI pair programmer we'll use in VS Code
  • GitHub Pro: Unlimited private repositories
  • Many other development tools and services

Apply at: education.github.com/pack

Note: You'll need to verify your student status using your @berkeley.edu email address.

Step 3: Accept GitHub Classroom Invitation

Once you have your GitHub account, you'll receive an invitation to join our GitHub Classroom organization (link will be provided via email before the first class).

terminal 2. Install VS Code (Visual Studio Code)

Our primary development environment

Download and Install

Download VS Code for your operating system: code.visualstudio.com

Install GitHub Copilot Extension
  1. Open VS Code
  2. Click the Extensions icon in the left sidebar (or press Ctrl+Shift+X / Cmd+Shift+X)
  3. Search for "GitHub Copilot"
  4. Click "Install"
  5. Sign in with your GitHub account when prompted
Alternative: Google Antigravity IDE

We'll also explore Google's new Antigravity IDE, which is based on VS Code. Details will be provided in class.

smart_toy 3. Python Installation

We'll guide you through Python setup in the first class

While you don't need to install Python before the first class, if you'd like to get a head start:

Recommended: Miniforge

We recommend using Miniforge (a lightweight conda distribution):

  1. Download from github.com/conda-forge/miniforge
  2. Follow the installation instructions for your operating system
  3. We'll set up environments together in class
Don't worry if you run into issues! We'll work through Python setup together in the first session.

add_circle 4. Optional: Continue.dev (Open-Source AI Assistant)

We'll also explore Continue.dev, an open-source alternative to GitHub Copilot that works with various LLM providers.

Installation instructions will be provided in class. This is optional and we'll set it up together if you're interested.

More info: continue.dev

help Need Help?

If you encounter any issues during setup, don't worry! Please:

  • Email cboettig@berkeley.edu or estacy@berkeley.edu
  • Come to the first class - we'll help troubleshoot any issues
  • Office hours will be announced in the first week
