Week 1 • Module 1

Session 2: Hello Climate

Your first AI-assisted data analysis

Today you'll load real-world CO2 emissions data, explore it with AI assistance, and create your first climate data visualization.

Prerequisites

Make sure you have:

  • VS Code with GitHub Copilot extension
  • GitHub Student Developer Pack approved (or use Antigravity IDE as alternative)
  • Your Module 1 repository cloned locally

The Data

We're using the Our World in Data CO2 and Greenhouse Gas Emissions dataset — one of the most comprehensive open datasets on global emissions.

50,000+ data points 254 countries & regions 1750–2024 years covered

Key columns we'll use:

  • country, year — identifiers
  • co2 — total emissions (million tonnes)
  • co2_per_capita — emissions per person
  • coal_co2, oil_co2, gas_co2 — by fuel type

View full documentation →

Part 1: Environment Setup

Open a terminal in VS Code and ask your AI assistant:

"Create a Python virtual environment and install pandas and matplotlib"

You should get something like:

python3 -m venv .venv
source .venv/bin/activate
pip install pandas matplotlib

Then download the data:

"Download the CSV from https://owid-public.owid.io/data/co2/owid-co2-data.csv to a data folder"

Part 2: Load and Explore

Create a new file called hello_climate.py and ask your AI:

"Load the OWID CO2 data CSV and show me basic info: how many rows, columns, years, and countries"

What to look for:

  • How big is this dataset? (rows × columns)
  • What time period does it cover?
  • What are the column names?

💡 Try df.info(), df.describe(), and df.head() to explore any DataFrame.

Part 3: Create a Trend Line

Ask your AI:

"Filter the data to just 'World' emissions from 1900 onwards, and create a line chart showing CO2 over time with labels"

Why filter for 'World'? The dataset includes individual countries AND aggregated regions. 'World' gives us the global total.

Why start from 1900? Earlier data is sparse and incomplete.

Save your chart:

plt.savefig('global_co2_trend.png')

Part 4: Go Further (If Time Permits)

Try these extensions:

  • Compare countries: "Plot CO2 for the US, China, and India on the same chart"
  • Per capita: "Compare CO2 per capita between the US and EU over time"
  • By fuel type: "Create a stacked area chart of coal, oil, and gas emissions"
  • Top emitters: "Bar chart of the top 10 emitters in 2022"

What to Commit

Before leaving, push your work:

git add .
git commit -m "Session 2: Hello Climate exercise"
git push

Your repo should contain:

  • hello_climate.py (or .ipynb)
  • data/owid-co2-data.csv
  • global_co2_trend.png

Key Takeaways

  1. AI assistants accelerate exploration — You didn't need to memorize pandas syntax
  2. Real data is messy — Notice all those missing values and aggregated regions
  3. Climate data tells a story — The upward trend in CO2 is unmistakable
