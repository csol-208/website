# Climate Solutions Course Website

This repository contains the course website for **AI-Augmented Data Science for Climate Leadership** at UC Berkeley.

## GitHub Pages Deployment

This site is built using Material Kit 3 by Creative Tim and is deployed via GitHub Pages.

### Local Development

To view the site locally, simply open `index.html` in a web browser or use a local server:

```bash
python -m http.server 8000
```

Then navigate to `http://localhost:8000`

## Structure

- `index.html` - Main landing page with course overview
- `syllabus.html` - Detailed 14-session syllabus
- `assets/` - MaterialKit CSS, JS, and component files
- `images/` - Course images (banner, logo)
